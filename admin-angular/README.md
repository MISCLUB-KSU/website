# لوحة التحكّم — Angular

إعادةُ بناء لوحة طلبات العضوية بـAngular، **بالتوازي مع لوحة Next القائمة**
لا بديلًا فوريًّا عنها (قرار ١٦ أغسطس ٢٠٢٦).

---

## التشغيل

```bash
cd admin-angular
npm install
npm run setup:env     # يولّد الإعداد من ../.env.local
npm start             # http://localhost:4200
```

`setup:env` يقرأ `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
من `.env.local` في مشروع Next ويكتبهما في `src/environments/environment.ts`
(**مُتجاهَل في git**). القالبُ وتعليلُه في `environment.example.ts`.

---

## ما بُني في هذا الإصدار

| | |
|---|---|
| تسجيل الدخول | رابطٌ إلى البريد + رمزٌ بديل، نفس طريقة لوحة Next |
| حارسُ المسار | ينتظر استعادةَ الجلسة قبل أن يقرّر |
| جدولُ الطلبات | بحثٌ وتصفيةٌ بالحالة وعدّاداتٌ لكل حالة |
| ملفُّ المتقدّم | لوحٌ جانبيّ ببياناته ورغباته وخبرته |
| تغييرُ الحالة | يُكتب في القاعدة، والصفُّ يُحدَّث من ردّها لا من القيمة المُرسَلة |

## ما لم يُبنَ بعد

- **لوحةُ التحليلات** (`dashboard.tsx` في Next — اثنتا عشرة بطاقةً ورسومُ SVG).
- **إرسالُ بريد القرار.** مفتاح Resend سرٌّ لا يُشحن في حزمةِ متصفّح؛ يبقى
  في مسار Next أو ينتقل إلى دالّةِ حافّة في Supabase.
- **تحميلُ السيرة الذاتية.** يمرّ اليوم برابطٍ موقَّع يُنشئه
  `/admin/cv/[id]` في Next. نقلُه يحتاج قرارًا: سياسةَ تخزينٍ تسمح للعميل
  بالتوقيع، أو دالّةَ حافّة.
- **شاشةُ `flow`.**

حتى ذلك: **لوحةُ Next تبقى شغّالة وهي المرجع في الموسم.**

## الأمان — اقرأ هذا قبل أي تعديل

⚠️ **الحاجزُ الأمنيّ في القاعدة لا في هذا التطبيق.**

الاستعلامُ `select("*")` بلا شرطٍ واحد، والذي يقصّ الصفوف هو `RLS`: قائدُ
اللجنة يستقبل صفوفَ نطاقه، ومن ليس في `staff` يستقبل **صفرًا**. ولهذا يصحّ
أن يقرأ تطبيقُ متصفّحٍ مباشرةً بالمفتاح العامّ — المفتاحُ لا يمنح شيئًا،
والجلسةُ هي ما يُعرّف القارئ.

**فلا يُضاف هنا منطقُ صلاحياتٍ يُظنّ أنه يحمي.** أيُّ فلترةٍ في الواجهة
راحةٌ للقارئ، ومن أرادها تجاوزها باستدعاءٍ مباشر. الحمايةُ تُضاف في
سياسات `supabase/migrations/` وحدها.

⛔ **و`SUPABASE_SERVICE_ROLE_KEY` لا يدخل هذا المجلّد بأي حال.** يتخطّى
`RLS` كلَّه، وتطبيقُ متصفّحٍ يحمله يعني أن أيّ زائرٍ يفتح أدوات المطوّر
يقرأ كلَّ طلبٍ في القاعدة برقم أحواله.

⚠️ **ورقمُ الأحوال (`national_id`) أخطرُ حقلٍ في الصفّ.** لا يُطبع في
سجلّ، ولا يدخل رسالةَ خطأ، ولا يُصدَّر، وليس حقلَ بحث. يُعرض في ملفّ
المتقدّم وحده — لا في الجدول.

## قراراتٌ بُنيت عليها الشيفرة

**رموزُ التصميم تُستورَد من الموقع ولا تُنسخ.** `src/styles.css` يستورد
`../../src/app/tokens.generated.css` بمسارٍ نسبيّ — المصدرُ الوحيد المولَّد
من `brand/v2/tokens.css`. ونسختان تفترقان أوّلَ ما تُعدَّل إحداهما، ولا
أحدَ يفتح الاثنتين ليقارن. وهذا أحدُ سببَي وضعِ التطبيق في المستودع نفسِه.

**الخطّان من Google لا مستضافان ذاتيًّا** — بخلاف الموقع. الموقعُ يمنع
طلبًا خارجيًّا عن **زائرٍ عامّ**، واللوحةُ خلف تسجيل دخولٍ يستعملها عشرة
أشخاص فالمقايضةُ تنقلب. ويوم تُنقل إلى نطاق النادي تُستضاف ذاتيًّا مثلَه.

**`Application` نسخةٌ ثانيةٌ من `Row`** في `src/app/admin/stats.ts` —
دَينٌ مقصود: التطبيقان لا يتشاركان `tsconfig`. **يُعدَّلان معًا**، والحلُّ
النهائيّ `supabase gen types`.

**RTL:** الجذر `dir="rtl" lang="ar"`، وكلُّ نصٍّ لاتينيّ أو رقمٍ يُغلَّف
`dir="ltr"` في موضعه — قاعدةُ المستودع، وأكثرُ ما يُنسى فينعكس بصريًّا.

## الفحص

```bash
npx tsc --noEmit -p tsconfig.app.json
npm run build
```

ولوحةُ Next لا تتأثّر: `admin-angular` مستثناةٌ في `tsconfig.json` بالجذر،
وإلّا التقطها `tsc --noEmit` هناك وفشل البناء على شيفرةٍ ليست له.
